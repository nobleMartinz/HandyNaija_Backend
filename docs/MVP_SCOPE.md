# MVP Scope

## In-Scope (MVP)

### Core Features
- User registration and authentication (customer/provider)
- Provider profile creation and management
- Service category browsing
- Service posting by providers
- Request creation by customers
- Provider search and matching
- In-app messaging between customers and providers
- Request status tracking (pending ? accepted ? scheduled ? in_progress ? completed)
- Reviews and ratings system
- Admin dashboard for user management
- Payment integration (Flutterwave)

### User Roles
- Customer
- Provider
- Admin

### Platform Features
- Mobile-responsive web application
- Email notifications
- Push notifications (basic)
- Rate limiting
- JWT authentication

## Out-of-Scope (MVP)

### Post-MVP Features
- Video calls
- Advanced analytics
- Loyalty programs
- Subscription plans for providers
- Multi-language support
- Advanced search filters (distance, availability, price range)
- Provider verification badges
- Emergency service booking
- Recurring bookings
- Wallet and escrow system
- Advanced reporting and analytics
- API for third-party integrations
- Mobile native apps
- Chatbot support
- Social login (Google, Facebook)
- SMS notifications
- Voice messages

## Success Metrics
- 1,000+ registered users in first 3 months
- 500+ service requests per month
- 80%+ request completion rate
- Average response time under 5 minutes
- 4.5+ average rating
- <5% dispute rate
- 95%+ uptime

## Timeline
- Phase 1 (Weeks 1-4): Core features, basic UI
- Phase 2 (Weeks 5-8): Payment integration, notifications
- Phase 3 (Weeks 9-12): Admin dashboard, analytics
